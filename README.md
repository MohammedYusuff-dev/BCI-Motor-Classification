# BCI Motor Classification

This repository contains Python-based Brain-Computer Interface (BCI) pipelines using **MNE-Python**, **Scikit-Learn**, **Common Spatial Patterns (CSP)**, and **Linear Discriminant Analysis (LDA)** to classify motor activity from EEG signals in the PhysioNet EEG Motor Movement/Imagery Dataset.
